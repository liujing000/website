## 🛠️ 本地开发

无需任何依赖，两种方式任选：

**方式一：直接打开**

用浏览器直接打开 `index.html` 即可。

**方式二：本地服务器**

```bash
# Python 3
python3 -m http.server 8000

# 或使用 Node.js
npx serve .
```

然后访问 👉 **http://localhost:8000**
